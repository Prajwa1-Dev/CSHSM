CSHSM Frozen Architecture & Research Invariants

The CSHSM (Counter-Speech Generation for Hate Content on Social Media) system implements a hybrid adaptive routing architecture designed to balance factual precision, retrieval reliability, and generation flexibility under strict safety gating.

1. Non-Hate Early Exit

When input text is classified as non-hate by the multitask classifier, the pipeline halts immediately without executing vector retrieval or generation fan-out, returning NON_HATE_EARLY_EXIT.

2. High-Similarity Retrieval vs Generation Fan-Out

If hate is detected, top-1 cosine similarity s1 is evaluated against calibrated threshold τ = 0.80:

  • If s1 ≥ τ: Routes to RETRIEVAL. Candidate is verified through M11 final safety gate. Retains quality_status="filtered_candidate".
  • If s1 < τ or error: Routes to FALLBACK_GENERATION. Executes concurrent 5-model fan-out, structural validation, M10 multi-criteria ranking, and M11 safety gating.

3. Defense-in-Depth Safety Invariant

Under no circumstances does an unreviewed candidate get automatically approved. Both retrieved and generated candidates pass through the independent final safety gate (safety_filter). Any violation immediately triggers safe fallback ("I cannot respond to this respectfully.").

4. Research Environment Mode

Running on Flask 3.1.3 in Milestone 8 Hybrid Demonstration Mode. The pipeline executes offline with real Multitask XLM-R neural classification, real BAAI/bge-m3 dense embedder and FAISS IndexFlatIP vector search over the committed 300-record Knowledge Base V2, and deterministic mock components for 5-model generation fan-out and candidate evaluation.
